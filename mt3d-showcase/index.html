目前成果

以下數字都由《MT_3D零件總表.xlsx》算出，總表重建後重新產生本頁即可更新。

    完成　依 2D 圖完整建模。
    簡化外形　有料號但沒有 2D 圖的標準件，只畫外形供組裝參考。
    共用　與其他系列同料號，只建一次，連到原系列的檔案。
    待補資料　缺料號、圖或尺寸，補齊後再建。
    不建模　沒料號的通用標準件，以及決定不建的件，只列表。

    怎麼做的

    每個零件都用程式依圖面尺寸建模，所以圖面改版時可以整批重建，不用一件一件手畫。

    1. 取最新版圖面

      「data_最新版」每個圖面只留最新版；原始 data 資料夾不動，當備份。

    2. 讀 2D 圖

      DWG 用 ODA File Converter 轉成 DXF，程式讀取輪廓線與尺寸標註。

    3. 程式建模

      依圖面尺寸用 CadQuery 逐件建實體，車削件、折彎件、平板件各有建法。

    4. 自動檢查

      幾何有效、外形與圖面差 ≤ 0.5 mm、STEP 重新匯入體積一致，才會輸出。

    5. 輸出與總表

      每件一個 STEP＋四視圖 PNG，零件總表整份自動重寫；全部重建約 95 秒。

    建檔原則

    • 同一張圖有多版時，紅框／109 年修正優先，標「錯」的不用，原廠圖只當參考。
    • 視圖之間有矛盾時，以有標尺寸的視圖為準，差異寫進總表。
    • STEP 為 AP214、單位 mm，可匯入 SolidWorks、Inventor、AutoCAD。
    • 同一料號只建一次，其他系列標「共用」並連到原檔。
